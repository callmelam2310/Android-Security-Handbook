# Android Security Handbook

Notes & tra cứu bảo mật Android — từ nền tảng đến khai thác, phân tích malware và forensics.

## Nội dung

| # | Module | Chủ đề |
|---|--------|--------|
| 00 | Android Fundamentals | Kiến trúc OS, mô hình bảo mật, components & IPC, môi trường test |
| 01 | Static Analysis | Trích xuất APK, đọc mã, native/hybrid, deobfuscation, patching |
| 02 | Dynamic Analysis | Frida hooking, WebView/deep link, intercept HTTP/S, bypass pinning |
| 03 | Pentest Automation | MobSF, Quark, Drozer, Objection, Medusa |
| 04 | Attacks | OWASP Mobile Top 10 (M1–M10) + MASVS |
| 05 | Malware Analysis | Nhận diện, IOC, evasion, custom VM, chiếm OTP/2FA |
| 06 | Forensics | Acquisition, root, ALEAPP, Autopsy, backup analysis |
